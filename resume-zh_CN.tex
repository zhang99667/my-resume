\textbf{项目介绍：}基于Java和Netty实现的高性能RPC框架。通过注解和配置文件快速使用框架，像本地调用一样调用远程服务。实现了负载均衡、重试和容错策略，支持HTTP和自定义协议、SPI动态扩展和后台统计。\\

\techlist{SpringBoot, Netty, ZooKeeper, SpringMVC, MySQL}
\begin{onehalfspacing}
  \begin{itemize}
    \item 基于Netty实现提供者和消费者间的高性能网络通信, 并对原有处理器进行增强解决了\textbf{半包粘包问题}。
    \item 使用本地对象维护服务提供者节点缓存, 减少与注册中心通信次数, 并\textbf{使用idle监听节点的过期自动更新本地缓存}, 提高了服务查询效率。
    \item 提供了\textbf{一致性Hash、轮询、随机等负载均衡算法}, 提高了提供者集群处理能力。
    \item 基于Guava Retrying实现了fixedWait等多种\textbf{重试机制}, 在\textbf{容错机制}上设计了FailOver、FailBack等多种重试策略。
    \item 使用类Dubbo的紧凑型消息结构实现\textbf{自定义RPC协议}, 提升网络传输性能。并且原生支持HTTP协议。
    \item 利用\textbf{SPI机制}提供了高可扩展的序列化器、负载均衡、重试重错机制和注册中心支持。
    \item 使用\textbf{基于注解驱动的SpringBoot Starter}封装了提供者和消费者的启动类。
  \end{itemize}
\end{onehalfspacing}

\textbf{项目介绍：}多导经络动态智能检测系统是一个针对医疗服务提供商的高度集成化的医疗健康监测平台，根据动态监测人体的奇经八脉和十二正经给出合理的医疗判断，实现了对用户健康数据的实时动态监测，提高了医疗判断的准确性。同时，平台提供了对个人开放的可移动经络检测设备等的购买服务，相应的也会提供对应的优惠券进行力度折扣。\\
\textbf{技术架构：}
\techlist{SpringBoot, MybatisPlus, Redisson, SpringSecurity, JWT, SpringTask, MQ}
\begin{onehalfspacing}
  \\
  \textbf{用户认证与授权：}
  \begin{itemize}
    \item 使用Spring Security+JWT对登录用户进行认证鉴权, 并通过Redis存储鉴权信息, 实现安全可靠的会话控制。
    \item 通过\textbf{Filter和Interceptor分离验证和刷新Token策略}, 通过\textbf{责任链模式}增强代码模块化和可维护性。
  \end{itemize}

  \textbf{经络检测结果处理：}
  \begin{itemize}
    \item 利用\textbf{反射机制动态封装和解析经络检测结果}, 提高代码的通用性和灵活性, 适应多种数据格式和多种检测设备。
    \item 使用AOP+注解的方式对数据持久化操作中的\textbf{公共字段自动填充}, 减少代码冗余, 提高开发效率。
  \end{itemize}

  \textbf{优惠券发放与高并发处理：}

    结合Redisson分布式锁和MySQL乐观锁, 在\textbf{解决优惠券超抢问题}并\textbf{实现一人一单}的情况下, 进一步提升并发处理能力。
