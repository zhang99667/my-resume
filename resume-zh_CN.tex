\datedsubsection{\textbf{半屏落地页 SDK 化（落地页，25Q3）}}{}
\begin{onehalfspacing}
  把散落在多条产品线的 H5 半屏容器收敛为一个可跨宿主复用的统一 SDK，并在此基础上打通预渲染。
  \begin{itemize}
    \item \textbf{容器架构统一}：三套容器各自实现，协议与能力互不复用；SDK 又依赖宿主完整工程，因此无法独立演进。将三套容器收敛为统一 SDK：通过 \texttt{compileOnly} 声明宿主能力约定，运行期由宿主注入实现，做到编译期解耦、运行期复用宿主已有能力；打通浏览框架生命周期与商业插件链路，并通过物料协议兼容层兼容历史差异，存量物料无需改动即可接入。统一后，新能力只需在 SDK 中实现一次，容器维护由三套收敛为一套，后续业务接入无需重复改造。（获 2026Q1 百度小赞·重大项目）

    \item \textbf{预渲染适配（成功率 0\% → 72\%）}：旧容器不在宿主统一链路上，预渲染池取不到实例，成功率长期为 0。迁移后接管池查找、实例复用与命中日志整条链路，补齐匹配失败时的降级与埋点，成功率提升至 72\%；命中场景下，首屏 P80 降低 700ms，页面到达 PV 提升约 6\%（以 JS 加载完成作为判定统计口径）。
  \end{itemize}
\end{onehalfspacing}

\datedsubsection{\textbf{激励视频 - 26Q1}}{}
\begin{onehalfspacing}
  \begin{itemize}
    \item \textbf{激励视频组件化重构}：针对单页面逻辑集中的问题，将播放、倒计时、任务、弹窗、UI 等按职责拆分为可复用组件，页面只做编排、组件间通过统一接口通信，降低耦合，提升迭代与复用效率。
    \item \textbf{弹窗优先级管理}：激励视频弹窗的展示时机与互斥关系原先分散在各自实现里，同时满足条件时会叠加、该弹的被压掉。改为注册时声明优先级、互斥组和降级链，由管理器统一决定展示顺序：冲突按优先级让路、展示失败自动降级、状态随页面生命周期复位。改造后新增弹窗只需注册、不用再改展示链路；叠加与漏弹从机制上消除，状态残留也不再依赖人工复位。
  \end{itemize}
\end{onehalfspacing}
